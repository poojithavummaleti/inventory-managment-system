# Inventory Management System

A simple desktop inventory management application developed using C#, WPF and .NET.

## Technologies Used

* C#
* WPF
* .NET
* XAML

## Features

* Add products
* Update products
* Delete products
* Display product information
* Calculate total inventory value
* Basic input validation

## Concepts Used

* C# Classes and Properties
* ObservableCollection
* DataGrid
* Event Handling
* WPF Controls
* XAML
* Basic Input Validation

## How to Run

1. Clone or download the repository.
2. Open the solution/project in Visual Studio.
3. Build the project.
4. Run the application using F5.

## Project Purpose

This project was created to practice C# programming and WPF desktop application development.
